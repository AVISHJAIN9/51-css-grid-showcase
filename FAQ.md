# Frequently Asked Questions (FAQ)

### What is the primary purpose of CSS Grid Layout Revision Suite?
Modular CSS Grid layout revision and responsive playground showcasing modern viewport units and subgrid.

### What technology stack is utilized?
HTML5, CSS Grid / Subgrid, Responsive Layouts.

### How do I run this locally?
Clone the repository and serve the assets using a static HTTP server or run the development script according to `package.json`.
